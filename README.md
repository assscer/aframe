# A-Frame Project 🚀

Этот проект создан с использованием **A-Frame** для демонстрации 3D-объектов и их динамических изменений.

## 📌 Функционал:
- **Кастомный компонент (`my-custom-component`)** — добавляет текст в 3D.
- **Демонстрация A-Frame компонентов** — есть две страницы (`index.html`, `sphere.html`).
- **Загрузка конфигурации из JSON** (`config.json`).
- **GUI (`lil-gui`)** — позволяет изменять текст и цвет текста в реальном времени.
- **Вращающийся объект** — `rotation-component.js` для анимации.
